---
title: 離線知識庫
---

用 Ollama 和 sqlite-vec 在自己電腦上建知識庫，不需要 API key，資料也不會離開本機。

## 準備

```bash
pip install hydrogen-ai hydrogen-ai-sqlitevec
ollama pull gemma3
ollama pull nomic-embed-text
```

把要查詢的 Markdown 筆記放進 `./notes` 資料夾。

## 程式

存成 `kb.py`：

```python
import asyncio
import sys

from hai.core import BaseNode, Flow
from hai.embedders.openai.openai import EmbeddingProcessor, QueryEmbedder
from hai.loader import MarkdownLoader
from hai.processor import ChunkProcessor, RecursiveSplitter
from hai.providers import OllamaText, ProviderEmbedding
from hai.vectorstores import VectorStoreRetriever, VectorStoreWriter
from hai.vectorstores.sqlitevec import SqliteVecStore

embedder = ProviderEmbedding(
    name="ollama-embedding",
    api_key="ollama",
    base_url="http://localhost:11434/v1/embeddings",
    model="nomic-embed-text",
)
llm = OllamaText(model="gemma3", timeout=300)


class AssignIds(BaseNode):
    """用檔名和段落編號當 id，重複導入時會覆蓋而不是新增。"""

    async def exec(self, context):
        for chunk in context["embedded_chunks"]:
            chunk["id"] = f"{chunk['source']}#{chunk['chunk_index']}"


class BuildMessages(BaseNode):
    async def exec(self, context):
        references = "\n\n".join(
            f"[{doc['name']}]\n{doc['content']}" for doc in context["retrieved_documents"]
        )
        context["messages"] = [
            {"role": "system", "content": "只根據參考資料，用繁體中文回答。找不到答案就說不知道。"},
            {"role": "user", "content": f"參考資料：\n{references}\n\n問題：{context['query']}"},
        ]


async def ingest(store):
    loader = MarkdownLoader(source="./notes", recursive=True)
    chunker = ChunkProcessor(splitter=RecursiveSplitter(chunk_size=500, chunk_overlap=50))
    embed = EmbeddingProcessor(embedder=embedder, batch_size=16)
    loader >> chunker >> embed >> AssignIds("ids") >> VectorStoreWriter(store=store)

    result = await Flow(loader).run({})
    print(f"導入 {result['document_count']} 份文件，{result['stored_count']} 個段落")


async def ask(store, question):
    query = QueryEmbedder(embedder=embedder)
    query >> VectorStoreRetriever(store=store, top_k=4) >> BuildMessages("prompt") >> llm

    result = await Flow(query).run({"query": question})
    print(result["assistant_message"])
    print("\n來源：", ", ".join({doc["name"] for doc in result["retrieved_documents"]}))


async def main():
    store = SqliteVecStore(path="notes.db", collection_name="notes")
    try:
        if sys.argv[1] == "ingest":
            await ingest(store)
        else:
            await ask(store, " ".join(sys.argv[2:]))
    finally:
        await store.close()


asyncio.run(main())
```

## 使用

```bash
python kb.py ingest
python kb.py ask 上次會議決定了什麼？
```

筆記更新後再跑一次 `ingest`，同一段落會覆蓋舊的資料。

## 換模型

`gemma3` 換成任何 `ollama pull` 過的模型，例如 `qwen3`、`llama3.1`。換 embedding 模型的話，要刪掉 `notes.db` 重新導入。
