## Context

`Flow.run()` 收一個 dict，每個節點從裡面讀資料、把結果寫回去，跑完回傳同一個 dict。

```python
result = await Flow(chunker).run({"documents": docs})
result["chunks"]
```

串接節點時，後一個節點要讀的欄位，前一個要寫出來。內建節點用的欄位：

| 節點                             | 讀取                            | 寫入                                                                  |
| -------------------------------- | ------------------------------- | --------------------------------------------------------------------- |
| Loader                           |                                 | `documents`、`document_count`                                         |
| `Cleaner`                        | `text`、`documents`             | `text`、每個 document 的 `content`                                    |
| `Splitter` / `RecursiveSplitter` | `text`                          | `text_chunks`、`chunk_count`                                          |
| `ChunkProcessor`                 | `documents`                     | `chunks`、`total_chunks`                                              |
| `ProviderEmbedding`              | `input`                         | `embeddings`                                                          |
| `EmbeddingProcessor`             | `chunks`                        | `embedded_chunks`                                                     |
| `VectorStoreWriter`              | `embedded_chunks`               | `stored_ids`、`stored_count`                                          |
| `QueryEmbedder`                  | `query`                         | `query_embedding`                                                     |
| `VectorStoreRetriever`           | `query_embedding`               | `retrieved_documents`、`retrieved_count`                              |
| 文字模型                         | `messages`、`tools`、`on_chunk` | `assistant_message`、`messages`                                       |
| `MetadataExtractor`              | `chunks`                        | `extracted_metadata`、`metadata_count`                                |
| `FactExtractor`                  | `chunks`                        | `extracted_facts`、`extracted_entities`、`fact_count`、`entity_count` |
| `EntityExtractor`                | `chunks`                        | `extracted_entities`、`entity_count`                                  |
| STT                              | `audio`、`format`、`language`   | `transcript`                                                          |
| TTS                              | `speech_text`                   | `speech_audio`                                                        |

欄位對不上時（例如檢索結果要交給文字模型），中間加一個節點轉換：

```python
class BuildMessages(BaseNode):
    async def exec(self, context):
        context["messages"] = [{"role": "user", "content": context["query"]}]
```

## Document

Loader 產生的、`ChunkProcessor` 要吃的都是 `Document`：

```python
from hai.core import Document

doc = Document(
    content="Hydrogen AI documentation",
    name="intro.txt",
    metadata={"source": "./intro.txt"},
)

doc.content
doc.get("source")             # 讀 metadata
doc.get("missing", "預設值")
dict(doc.items())             # 轉成一般 dict
```

## Chunk

`ChunkProcessor` 產生的每個 chunk 是 dict，文件的 metadata 會一起帶過來：

```python
{
    "content": "一段文字",
    "name": "intro.txt",
    "chunk_index": 0,
    "total_chunks": 2,
    "source": "./intro.txt",
}
```
